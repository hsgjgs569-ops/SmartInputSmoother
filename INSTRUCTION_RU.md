# Инструкция (пошагово, для новичка): собрать и установить SmartInputSmoother

Мод предназначен для **Geometry Dash 2.2.0** (предпоследняя 2.2) и **Geode SDK 2.2.144**. Сборка идёт в облаке через GitHub Actions (ПК не нужен), результат — файл `.geode` для Android (arm64-v8a).

## 1. Загрузить файлы в новый репозиторий на GitHub
1. Зайдите на https://github.com и войдите в аккаунт (или зарегистрируйтесь).
2. Нажмите **«+»** (правый верхний угол) → **New repository**.
3. Укажите имя, например `SmartInputSmoother`, оставьте **Public** (или Private — Actions тоже работают), нажмите **Create repository**.
4. Загрузите файлы проекта в репозиторий (все файлы и папки из этого проекта, сохраняя структуру):
   - **Способ A (через веб, просто):** на странице репозитория нажмите **Add file → Upload files**. Перетащите содержимое папки проекта: `mod.json`, `CMakeLists.txt`, `README.md`, папку `src/` (с `main.cpp`), папку `.github/workflows/` (с `build.yml`). Важно: `.github/workflows/build.yml` должен лежать именно по этому пути. Нажмите **Commit changes**.
     - Если веб-интерфейс не даёт создать папки с точкой: сначала **Add file → Create new file**, в имени введите `.github/workflows/build.yml`, вставьте содержимое файла, закоммитьте; затем загрузите остальные файлы/папки.
   - **Способ B (через git, если есть):**
     ```bash
     git init
     git add .
     git commit -m "Initial SmartInputSmoother"
     git branch -M main
     git remote add origin https://github.com/<ваш-логин>/SmartInputSmoother.git
     git push -u origin main
     ```

Проверьте, что в репозитории есть: `.github/workflows/build.yml`, `CMakeLists.txt`, `mod.json`, `src/main.cpp`.

## 2. Запустить сборку (вкладка Actions)
1. Откройте ваш репозиторий на GitHub.
2. Перейдите на вкладку **Actions** (вверху).
3. Если появится запрос включить workflow — нажмите **I understand my workflows, go ahead and enable them**.
4. Слева выберите workflow **Build Geode Mod**.
5. Запустите сборку: нажмите **Run workflow** → выберите ветку (обычно `main`) → **Run workflow** (также сборка запустится автоматически после push).
6. Дождитесь завершения (зелёная галочка). Если красный крестик — откройте запуск и посмотрите лог ошибки (часто это несовпадение версии SDK/окружения; см. примечание ниже).

## 3. Скачать готовый `.geode` файл
1. Во вкладке **Actions** откройте успешный (зелёный) запуск **Build Geode Mod**.
2. Прокрутите вниз до блока **Artifacts**.
3. Скачайте артефакт (обычно `SmartInputSmoother-geode` или аналогичное имя от combine-шага) — внутри будет файл вида `user.smartinputsmoother.geode` (или `.geode` пакет).
4. Распакуйте архив артефакта (zip), если `.geode` внутри него, и сохраните `.geode` на телефон.

## 4. Установить его в Geometry Dash на телефоне
1. Убедитесь, что на телефоне установлены **Geometry Dash 2.2** (нужная вам версия 2.2.0) и **Geode** для Android, совместимый с этой версией GD (линейка Geode 2.x / например 2.2.144, как указано в требованиях). Если Geode не установлен — установите его сначала (с официального сайта Geode для вашей версии GD).
2. Скопируйте файл `.geode` на телефон (через кабель, облако, мессенджер — как удобно).
3. Откройте **Geometry Dash** → нажмите кнопку/иконку **Geode** (обычно внизу/в меню) → раздел **Mods** / **Установленные моды**.
4. Установите мод одним из способов (зависит от версии Geode):
   - Кнопка **Install** / **+** / **Install from file** → выберите скачанный `.geode` файл; или
   - Положите `.geode` в папку модов Geode на устройстве (обычно `.../Android/media/com.geode.launcher/game/geode/mods/` или путь, указанный в вашем лаунчере/Geode) и перезапустите игру.
5. Перезапустите игру при необходимости, включите мод в списке Geode и настройте: **Enable**, **Target CPS** (10–60), **Smoothing Mode** (Linear/Burst).

## Примечание
- Workflow использует `geode-sdk/build-geode-mod@main`. Если для **Geode 2.2.144** потребуется явно указать версию SDK/CLI в action — откройте `.github/workflows/build.yml` и добавьте/измените параметры шага сборки согласно документации action (например, `sdk: 'v2.0.0'`/конкретный тег или `cli: ...`), затем перезапустите Actions.
- Мод перехватывает ввод и дробит удержание на микро-импульсы; отпускание физической кнопки мгновенно прекращает эмуляцию. Это настройка сглаживания ввода, а не автокликер, но использование модов в онлайне/рейтинг-игре может ограничиваться правилами — используйте офлайн/на своё усмотрение.
